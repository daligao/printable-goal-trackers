# Growth measurement

Use real values only. Record N/A when a source is unavailable.

| Metric | Source | Cadence |
| --- | --- | --- |
| Views, unique visitors, clones, stars | GitHub repository Insights | Weekly |
| Release downloads | GitHub Releases | Weekly |
| GitHub to CutDone referrals | Existing CutDone analytics using the supplied UTM links | Weekly |
| Print/use and paid conversion | Existing CutDone analytics, if available | Weekly |

No database, tracker, or CutDone analytics change is required. The repository uses
`utm_source=github`, `utm_medium=referral`, and `utm_campaign=printable_goal_trackers`.

## 7 / 14 / 30 day review

At each checkpoint, record actual traffic, downloads, referral behavior, reported
print issues, and template requests. Continue if people use/download resources or
offer actionable feedback; optimize if interest exists but the route to a PDF or
CTA is unclear; pause promotion if there is no meaningful signal after fixing
obvious discoverability and usability issues. Never invent targets or outcomes.
