# 2027 Goals Tracker

Keep the year visible without turning it into an overwhelming plan.

## Print and use

1. Limit this page to goals that genuinely matter this year.
2. Give every goal one next action and one milestone you can recognize.
3. Review the page regularly; revise the plan instead of abandoning it.

Print at **100% / Actual Size**. Both A4 and US Letter PDFs are included.

The worksheet is an original, printer-friendly resource from the printable-goal-trackers project.
