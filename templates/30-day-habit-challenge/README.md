# 30-Day Habit Challenge

Choose one habit, make it easy to start, and mark each day you show up.

## Print and use

1. Write one habit and a version small enough to do on a busy day.
2. Mark a day after you finish it; an imperfect streak still counts.
3. Use the weekly notes to notice what made the habit easier or harder.

Print at **100% / Actual Size**. Both A4 and US Letter PDFs are included.

The worksheet is an original, printer-friendly resource from the printable-goal-trackers project.
