# 7-Day Declutter Challenge

Make room gradually by focusing on manageable categories instead of an entire home.

## Print and use

1. Set a timer that feels manageable; stopping on time is part of the challenge.
2. Use the suggested area as a starting point and skip anything unsafe or sentimental.
3. Move donations and recycling out of the home promptly when you can.

Print at **100% / Actual Size**. Both A4 and US Letter PDFs are included.

The worksheet is an original, printer-friendly resource from the printable-goal-trackers project.
