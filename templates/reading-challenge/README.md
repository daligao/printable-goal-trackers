# Reading Challenge

Set a flexible reading intention and collect small notes as you go.

## Print and use

1. Choose a goal that fits your season: pages, minutes, books, or a mix.
2. Add a title when you start it and mark the finish when you are done.
3. Use the notes column for a quote, idea, or reason to recommend it.

Print at **100% / Actual Size**. Both A4 and US Letter PDFs are included.

The worksheet is an original, printer-friendly resource from the printable-goal-trackers project.
